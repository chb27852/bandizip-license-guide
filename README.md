## 先说 Bandizip 是个啥

Bandizip 是韩国 Bandisoft 出的压缩文件管理工具，支持 ZIP、RAR、7Z、TAR、ISO、IMG、LZH、BZ2、GZ 等 40 多种格式。基本上你网上能下到的压缩包，它都能开。

几个我觉得真正有用的功能：

- **多核并行压缩**：最高能提速 6 倍，大文件压起来不卡。免费版只能用 16 线程，专业版能拉满 64 线程
- **压缩包内图片预览**：不用解压就能看里面的图，整理素材素材库的时候这功能太香了
- **密码管理器 + 密码恢复**：常用密码存起来，忘了的还能暴力找回（专业版专属）
- **压缩包修复**：下到一半断了、文件损坏了，能尝试抢救有效数据
- **恶意软件扫描**：解压前先扫一遍，比解压完才发现中招强
- **AES256 加密**：正经的加密算法，不是糊弄人的

界面干净，右键菜单集成在资源管理器里，操作顺手。知乎上有人评价说"和 WinZip、WinRAR 相比，Bandizip 对 7z 格式支持更好；和一堆国产 X 压相比，又明显干净很多，不耍流氓"。微软商店的用户评论也差不多这个调调——"占用内存少，运行快，没有广告"。
